## 1. About CHI Lab

The **Computational Healthcare Intelligence Lab (CHI Lab)** develops computational and AI-driven approaches for healthcare research, with emphasis on:

- Artificial Intelligence and Machine Learning
- Computational Biology and Systems Biology
- Biomedical Modelling and Intelligent Healthcare Systems
- Medical Imaging and Digital Health
- Agentic AI and Multi-Agent Virtual Laboratories
- Data-driven therapeutic discovery and design

**Official Lab Page:**  
https://icriste.com/computational-healthcare-intelligence-lab-chi-lab/

## 2. ECR Research Repository

This repository provides a structured environment for **Early Career Researchers (ECRs)** to learn, implement, experiment, document, reproduce, and collaborate on research projects.

### ECR Pathway

**Learn → Read → Implement → Experiment → Analyse → Document → Reproduce → Collaborate → Publish**

---

## 3. ECR Levels

| Level | Focus |
|---|---|
| **ECR1-BS** | Coding, literature review, data analysis, basic AI/ML |
| **ECR2-MS** | ML/DL, modelling, biomedical data analysis, independent research |
| **ECR3-PhD** | Advanced AI, systems biology, agentic AI, methodology, publications and mentoring |

---

## 4. Mini Projects

Each mini project should include:

1. Research question
2. Short literature review
3. Dataset or computational resource
4. Methodology
5. Implementation
6. Experiments and analysis
7. Results and discussion
8. Reproducible code
9. Documentation
10. References

Projects should progress from **small reproducible studies** toward independent research contributions.

## 6. Literature & Research Practice

ECRs should maintain a focused literature collection and record:

- Research problem
- Dataset
- Methods
- Main findings
- Limitations
- Relevance to the project

Priority should be given to **recent, peer-reviewed, reproducible research**.

---

## 7. Reproducibility

Every project should clearly document:

- Software and libraries
- Dataset sources
- Processing steps
- Model/configuration details
- Evaluation metrics
- Experimental results
- Random seeds where applicable
- Instructions for reproducing the work

Where appropriate, projects should provide **Google Colab notebooks, scripts, figures, tables, and supporting documents**.

## 10. Project Quality Checklist

Before completing a project, confirm:

- [ ] Research question is clearly defined
- [ ] Relevant literature is reviewed
- [ ] Dataset/source is documented
- [ ] Methodology is explained
- [ ] Code is organised and reproducible
- [ ] Experiments are properly evaluated
- [ ] Results are documented
- [ ] Figures/tables are understandable
- [ ] Limitations are discussed
- [ ] References are complete

## 11. Collaboration

ECRs are encouraged to:

- Share ideas and computational resources
- Review each other's work
- Reproduce published methods
- Collaborate across ECR levels
- Develop interdisciplinary projects
- Contribute to manuscripts and research outputs

---

## 12. Ethics & Responsible Research

All projects should follow responsible research practices, including:

- Respect for privacy and confidentiality
- Appropriate use of biomedical data
- Reproducible and transparent methods
- Responsible AI development
- Proper attribution and citation
- Honest reporting of results and limitations
